# Vídeos gravados (brutos)

Pasta para os vídeos gravados no computador (screen recordings dos sites) que ainda vão ser cortados e limpos.

**Como pôr aqui os vídeos:** abrir este link e arrastar os ficheiros para a página:
https://github.com/tspacheco/Designerpacheco/upload/claude/awesome-knuth-8hnx4j/videos/brutos
Depois carregar em "Commit changes". Os nomes podem ficar como estão.

- Limite do site do GitHub: **25 MB por ficheiro**. Um vídeo maior tem de ser comprimido antes
  (QuickTime: Ficheiro → Exportar como → 1080p; ou HandBrake, preset "Fast 1080p30") ou enviado
  com o GitHub Desktop, que aceita até 100 MB.
- Formatos: .mp4, .mov ou .webm.

Os vídeos cortados e prontos para os anúncios ficam em `videos/prontos/`.
