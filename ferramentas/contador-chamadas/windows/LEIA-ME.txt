CONTADOR DE CHAMADAS (WhatsApp no PC) - Pacheco Studios

1. Extrair este zip para uma pasta (botao direito > Extrair tudo).
2. Duplo clique em instalar.cmd. Se o Windows avisar (SmartScreen): Mais informacoes > Executar mesmo assim.
3. Colar o codigo de acesso que o Tomas enviou e carregar Enter.
4. Aparece um icone (i) junto ao relogio. Botao direito > Enviar teste.

Funciona com a app WhatsApp para Windows (Microsoft Store ou whatsapp.com).
Nao funciona com o WhatsApp Web no browser.
Conta uma chamada sempre que o WhatsApp usa o microfone. Nao le nomes, numeros nem mensagens.
Arranca sozinho quando o PC liga. Para desligar: botao direito no icone > Sair.
