# Noir Barbershop — o que pedir ao dono

Para fechar o site (tudo o que está marcado «de confirmat»):

1. **Lista de serviços com preços e durações** (como estão no MERO) — o site remete para o MERO; se quiserem, mostramos os preços no site.
2. **Barba**: fazem? (contorno, aparar, toalha quente?) — está «de confirmat».
3. **Corte de rapaz/criança**: a partir de que idade e preço.
4. **A equipa**: nomes, fotos e especialidade de cada barbeiro (uma avaliação elogia o «Mihai»).
5. **WhatsApp**: o 0745 229 944 tem WhatsApp? (o SMS funciona sempre.)
6. **Avaliações para citar**: 2–3 frases de clientes, com autorização.
7. **Fotos**: a fachada real (a imagem da montra «NOIRCUT BARBERSHOP EST 2025» que está no Google parece gerada por IA — não a usámos), equipa, cortes recentes.
8. **Instagram / Facebook / TikTok / e-mail**.
9. **Denominação da empresa e CUI** para o rodapé.
10. **Domínio** desejado (ex.: noirbarbershop.ro).
11. Confirmar o horário: L–S 10–20, D 12–18 (é o que está no Google).
