# Mobile Motors Iași — o que pedir ao dono para fechar o site

Tudo o que falta aparece no site com o selo **„de confirmat”**.

1. **Horário completo** — só sabemos marți 07:00–22:00 (ficha Google). Faltam os outros dias.
2. **WhatsApp:** o site usa o **0752 266 817** para «Sună»; o formulário envia por WhatsApp ou SMS para o mesmo número. Confirmar que o número tem WhatsApp.
3. **Preços** (schimb de anvelope, îndreptat jante, freon, diagnoză) — hoje: «preț: de confirmat». Se houver lista de preços afixada, uma foto basta.
4. **Diagnoză auto:** está no painel, mas não há foto nem detalhe (que aparelho, que marcas). Mandar foto do aparelho em uso.
5. **Stoc de anvelope:** vendem anvelope noi e/ou second-hand? Marcas? (o site só diz «stocul: la telefon»).
6. **Pagina de Facebook** (m.facebook.com na ficha): link exato, para pôr no rodapé.
7. **Rodapé legal:** CUI da Mobile Motors Ltd SRL.
8. **Domínio:** p. ex. mobilemotors.ro (verificar se está livre).
9. **Fotos** em falta: ver `media/LEIA-ME.txt`.

A escala de «adâncime profil» (8,0 → 1,6 mm) é um elemento decorativo: 1,6 mm é o mínimo legal geral para pneus de turismo, não um dado do negócio.
