Questions that come up

Do I need to book?

Weekend evenings, it helps. During the week there is usually a table, but a short WhatsApp message keeps your place.

Large groups?

Up to 10 people, book here. Above that, use the groups form so we can arrange the platter.

Children?

Yes, and there are non-spicy dishes: momo, egg fried rice, cheese naan.

Running late?

We hold the table for 15 minutes. If you are later, write in the same chat and we keep it if we can.
